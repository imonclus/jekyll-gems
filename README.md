# Crea con las Gems de Gemini

Este proyecto es un sitio web estático construido con [Jekyll](https://jekyllrb.com/) que recopila una colección de **Gemas de Gemini** diseñadas específicamente para facilitar el trabajo diario de los educadores y profesores.

## 🌟 Características

- **Colección de Prompts (Gemas):** Prompts preconfigurados y listos para usar con Gemini en el ámbito educativo.
- **Categorización Clara:** Las gemas están organizadas por áreas de interés:
  - Evaluación, datos y calificación
  - Materiales didácticos y contenido
  - Uso e integración de la IA
  - Alfabetización y lenguaje
  - Herramientas orientadas al estudiante
  - Recursos de apoyo y diferenciación
  - Planificación de lecciones
  - Participación y juegos
  - Tareas profesionales y administrativas
  - Matemáticas, Ciencias y STEM
- **Búsqueda Integrada:** Buscador en tiempo real para encontrar rápidamente la gema ideal.
- **Diseño Responsivo:** Completamente adaptable a dispositivos móviles, tablets y escritorio.

## 🚀 Cómo ejecutar el proyecto localmente

Para ejecutar este sitio web en tu propia máquina, necesitas tener Ruby y Jekyll instalados.

1. Clona este repositorio o descarga los archivos.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta el servidor de Jekyll con el siguiente comando:
   ```bash
   bundle exec jekyll serve
   ```
4. Abre tu navegador web y visita `http://localhost:4000`.
